# India EV Market Intelligence Analysis

An interactive Power BI dashboard designed to analyse India's Electric Vehicle (EV) market, explore registration trends, evaluate manufacturer performance and understand the distribution of charging infrastructure across states.

## 📌 Project Overview

The **India EV Market Intelligence** project provides insights into India's electric vehicle ecosystem through interactive dashboards and data-driven analysis.

The project uses Power BI to transform raw datasets into meaningful visual insights, helping users explore EV sales, registrations, manufacturer rankings, vehicle categories and charging infrastructure.

## 🎯 Project Objectives

- Analyse electric vehicle sales and registration trends.
- Compare manufacturer performance and rankings.
- Understand the distribution of EV registrations across vehicle categories.
- Explore state-wise charging infrastructure.
- Identify important patterns and insights in the Indian EV market.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard development and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculated measures, time intelligence and analytical calculations
- **Data Modelling** – Star schema and table relationships

## 📊 Dashboard Pages

The report consists of five main analytical pages and a dedicated manufacturer drill-through page.

| Page | Description |
|---|---|
| EV Market Overview | Overall EV market performance and key metrics |
| EV Registration Trends & Time Intelligence | Monthly and yearly registration analysis |
| Manufacturer Performance Analysis | Manufacturer comparisons and Top/Bottom rankings |
| Charging Infrastructure & State Analysis | State-wise charging infrastructure analysis |
| EV Market Insights | Vehicle segment comparisons and key findings |
| Manufacturer Drill-through | Detailed manufacturer-level analysis |

## 🔍 Key Features

- Interactive slicers and cross-filtering.
- Dynamic manufacturer rankings.
- Top 100 and Bottom 100 manufacturer analysis.
- Manufacturer drill-through functionality.
- Dynamic manufacturer and vehicle images.
- Time-based registration analysis.
- Multiple Power BI visualizations.
- DAX-based calculations and measures.

## 📈 Key Insights

- Two-wheelers account for approximately **51.56%** of EV sales.
- Three-wheelers account for approximately **43.75%** of EV sales.
- OLA Electric Technologies leads the manufacturer sales ranking with approximately **588K sales**.
- Maharashtra leads the charging infrastructure comparison with **3,079 charging stations**, followed by Delhi, Karnataka and Kerala.

## 🧹 Data Preparation & Modelling

The project involved data preparation using Power Query, including:

- Removing duplicate and blank records.
- Cleaning and standardizing text fields.
- Correcting data types.
- Preparing dimension and fact tables.
- Building relationships using a star-schema-based data model.

DAX was used to create analytical measures, rankings, percentage calculations and time-intelligence metrics.

## ⚠️ Data Limitations

The EV registration dataset used in this project contains records only up to **August 2024**. Therefore, the registration analysis represents the available dataset period and should not be interpreted as current 2026 market statistics.
